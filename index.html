수행평가 진행 방법

카카오톡에서 링크를 바로 열어도 답안을 작성하고 저장할 수 있어요. 다만 카카오톡 안에서는 파일 다운로드가 제한되기 때문에, 저장 버튼을 누르면 작성한 답안을 그대로 가지고 외부 브라우저로 이동하거나 이미지로 저장하는 방법이 안내됩니다.

  • 아이폰 / 아이패드 : Safari(사파리) 권장
  • 갤럭시 : Chrome(크롬) 또는 삼성 인터넷 권장
  • PC : Chrome(크롬) 또는 Edge(엣지) 권장

작성 중인 답안은 이 기기에 자동으로 임시 저장돼요. 다른 기기로 옮길 때는 'HTML 저장'으로 받은 파일을 '저장 파일 불러오기'로 열면 이어서 작성할 수 있습니다.

수행평가 저장 방법

활동을 마친 후에는 아래 버튼 중 하나를 눌러 결과물을 저장해 주세요. 어떤 형식으로 저장하든 모든 단계의 질문과 답안이 함께 담깁니다.

  • PDF 파일 저장 (권장) : 인쇄 창을 거치지 않고 PDF 파일이 바로 만들어져요.
  • 이미지(PNG) 저장 : 한 쪽마다 이미지 한 장씩 만들어져요. 여러 장이면 모두 제출해 주세요.
  • HTML 파일 저장 : 웹페이지 파일로 저장돼요. 나중에 위쪽의 '불러오기'로 열어 이어서 작성할 수도 있어요.

기기별 저장 방법

  • 스마트폰 / 태블릿PC : 파일이 만들어지면 '공유하기'를 눌러 카카오톡 오픈 채팅방에 바로 보내거나, '파일 다운로드'로 기기에 저장하세요. 이미지는 길게 눌러 사진 앱에 저장할 수도 있어요.
  • PC : 원하는 형식의 저장 버튼 → '파일 다운로드'

PDF 또는 HTML 파일로 저장되지 않는 경우 이미지(PNG) 파일로 저장하거나 작성한 웹페이지를 직접 캡쳐하여 제출해도 됩니다.

저장한 결과물이 정상적으로 열리는지 확인한 뒤 '한국지리 탐구 오픈 채팅방'에 제출해 주세요.

※ 지각 제출 시 감점이 있으므로 반드시 제출 기한을 지켜 주세요.
