③ 지역과 지역 주민에게 미치는 긍정적·부정적 영향을 함께 고려할 것

4지역과 지역 주민에게 미칠 긍정적 영향

저장 방법
결과물 저장: 답안이 포함된 독립형 HTML 파일을 내려받습니다. 저장한 파일을 다시 열어 답안을 확인하거나 수정할 수 있습니다.
PDF 저장: 버튼을 눌러 인쇄 창에서 ‘PDF로 저장’을 선택하세요. 모든 단계의 답안이 포함됩니다.
이미지(PNG) 저장: 작성한 결과물을 페이지별 PNG 이미지로 저장합니다. 다운로드가 여러 번 실행될 수 있습니다.
임시 저장: 현재 브라우저의 로컬 저장소에 보관됩니다. 같은 브라우저에서 자동 복원되지만, 시크릿 모드·브라우저 데이터 삭제·파일 위치 변경 시 복원되지 않을 수 있습니다. 반드시 HTML 결과물도 별도로 저장하세요.
